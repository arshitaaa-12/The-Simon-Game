# Simon Game 🎮

A memory-based **Simon Game** built as part of **Angela Yu's Web Development Bootcamp**.

## Features

- Random color sequences
- Sound effects
- **Button animations
- Level tracking
- **Answer checking
- Game-over functionality

## Technologies Used

HTML • CSS • JavaScript • jQuery

## About the Project

I learned the steps to build this webpage through a certification course on Udemy. However, I implemented the code myself and practiced the concepts to make this a fully functioning webpage.
